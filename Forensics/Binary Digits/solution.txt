The first 16 bits are:

1111111111011000

Split them into 8-bit groups:

11111111 11011000

Convert to hex:

FF D8

FF D8 is the magic header of a JPEG image. Multiple picoCTF writeups confirm that digits.bin is a stream of binary digits representing a JPEG.

create decode.py
with open("digits.bin", "r") as f:
    bits = f.read().strip()

# Convert every 8 binary digits into one byte
data = bytes(
    int(bits[i:i + 8], 2)
    for i in range(0, len(bits), 8)
    if len(bits[i:i + 8]) == 8
)

with open("recovered.jpg", "wb") as f:
    f.write(data)

print(f"Recovered {len(data)} bytes")
